# Sharvani Rathore - Personal Portfolio

A sleek, responsive, and modern portfolio website showcasing projects, skills, and professional experience. This project focuses on high visibility for technical skills and a user-centric design approach.

## 🚀 Features

- **Responsive Navigation**: A mobile-optimized menu that transitions into a side drawer for smaller screens.
- **Interactive About Section**: Tabbed interface to switch between Skills, Experience, and Education without reloading the page.
- **Skills Showcase**: A dedicated white-card section using FontAwesome brand icons with custom brand-accurate colors.
- **Project Gallery**: A grid layout featuring project images with an animated "slide-up" overlay containing descriptions and links.
- **Contact Form**: A clean, integrated contact section with social media links and a functional layout for user inquiries.

## 🛠️ Tech Stack

- **HTML5**: Semantic structure of the web pages.
- **CSS3**: Custom styling, Flexbox/Grid layouts, and smooth hover animations.
- **JavaScript**: Tab switching logic and mobile menu toggle functionality.
- **FontAwesome**: Scalable vector icons for professional branding.
- **Google Fonts**: Poppins typeface for clean, modern readability.

## 📁 File Structure

- `index.html`: The core structure and content of the portfolio.
- `style.css`: All layout designs, color schemes, and media queries for responsiveness.
- `images/`: Directory containing project screenshots, logos, and profile imagery.

## 🔧 Installation & Usage

1. Clone the repository to your local machine.
2. Ensure you have an active internet connection to load the FontAwesome kit and Google Fonts.
3. Open `index.html` in any modern web browser (Chrome, Firefox, or Edge).
4. For the best experience, use a local server (like VS Code Live Server) to view changes in real-time.

## 📝 Customization

- **Updating Icons**: To change skill icons, update the `<i>` classes in `index.html` using [FontAwesome](https://fontawesome.com/icons) names.
- **Color Themes**: Global colors and section backgrounds can be modified in the `/* Global Styles */` section of `style.css`.
